# Jeje Abdul Rahman — Software Engineer Portfolio

Modern single-page portfolio redesigned for GitHub Pages.

## Run locally

Open `index.html` directly, or serve the folder with any static server.

## Deploy to GitHub Pages

Replace the files in your `jejeabdul.github.io` repository with this version and push to the branch used by GitHub Pages.

## Main files

- `index.html` — content and structure
- `css/style.css` — complete responsive visual system
- `js/main.js` — theme toggle, mobile menu, portfolio filters, modal, reveal animations
- `images/` — project screenshots (hero visual is an inline SVG in `index.html`)
